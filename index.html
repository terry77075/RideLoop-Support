Install or update

Beta access is handled personally by the outabit team through TestFlight.

  1. New tester? Request beta access below and follow the invitation sent by the outabit team.
  2. Already testing? Open TestFlight, select outabit, and install the update offered to you. Look for build 54.
  3. Keep the existing app installed when updating. If build 54 is not offered, contact support rather than deleting your app.

Android

Available to beta testers

v26 · version 1.1 · build 2026101226

Released: 2026-10-21

What’s new
  • Custom activities: add, rename, reorder, hide and restore activities, with independent goals and default screens. Hidden activities with outings remain in Stats.
  • Bluetooth sensor discovery now includes unnamed devices, merges duplicate advertisements, shows signal strength and sorts stronger signals first.
  • Compatibility clues distinguish previously connected sensors, likely compatible sensors and devices with unknown compatibility. Services are checked after you select Connect.
  • Long-press an activity on Home to customize it, with a direct return to Home.
Fixes
  • Normal Cancel no longer shows a misleading lost-sensor warning.
  • Empty Stats activity rows are omitted, and empty periods are explained.
Known issues
  • A build-specific known-issues list is not yet documented here. Please report anything unexpected.
Please help test
  • Check sensor discovery, live readings and reconnect behavior with your own sensor.
  • Try customizing and hiding activities; verify that saved outings and settings remain intact after updating.

Full release notes

Install or update

Ask the outabit team for beta access and the official Android installation instructions.

  1. New tester? Request beta access below. Use only the official installer and instructions provided by the outabit team.
  2. Already testing? Install the new beta over your existing beta app. Do not uninstall first, as this can remove local outings and settings.
  3. Keep Android security protections enabled. Stop and contact support if you see an unexpected signing or package mismatch.

Custom activities, your way

Available in the current iPhone and Android betas: outabit tracks outdoor outings with GPS rather than limiting you to a fixed activity list. Add and name activities, arrange or hide their Home buttons, and choose activity-specific goals and default dashboards.

Hiding an activity keeps its history. See Beta updates for platform-specific release details.
