Install RideLoop Beta

The current public stable beta is RideLoop v14. This is a test release, so back up anything important and expect occasional rough edges.

Download the latest RideLoop Beta

Fixed download link: RideLoop-Beta.apk

Opening this from email or a message? Use the message menu to open the link in your full browser (Chrome, Firefox, Edge, or Samsung Internet). Embedded email and chat viewers sometimes block APK downloads.

Install step by step

  1. Download. Tap the blue button above in your full browser. If asked whether to keep the file, confirm only when the address is on github.com/terry77075/RideLoop-Support.
  2. Find the APK. Open your browser's Downloads list, or open the Android Files app and choose Downloads. Look for RideLoop-Beta.apk.
  3. Allow this source only if Android asks. Tap the APK. If Android says this source is not allowed, open the setting offered by Android and allow installs for the one browser or Files app you are using. Return to the APK and try again. You can turn that source permission off after installation.
  4. Read the warning. Android may warn that APK files can be harmful. Continue only if the download came from the GitHub address above and the filename is correct. If the source or filename differs, cancel.
  5. Install and open. Tap Install, then Open. Grant only permissions needed for features you choose, such as location for route recording.
Keep Android security protections on. Do not disable Play Protect or broadly allow unknown apps. If Android reports a signature, package, or other unexpected security problem, cancel and use the support link below.

Updating RideLoop Beta

Use the same blue download button for future beta updates. Open the new APK and install it over the existing beta. Do not uninstall first: uninstalling can remove locally stored activity data.

Before updating: keep copies of any exported routes or activity information you cannot replace. RideLoop Beta installs as a separate beta app from any production RideLoop build.

First open and help

On first open, RideLoop may ask for location access. Choose the level needed for the way you intend to record activities. Android battery and background settings can affect recording while the screen is locked.
