# Install MyHealthData on Android

> **Android only.** The fixed link below always downloads the latest public release. The current latest release is 0.1.2.

## Download

[Download the latest MyHealthData (MyHealthData.apk)](https://github.com/terry77075/MyHealthData-Android-Releases/releases/latest/download/MyHealthData.apk)

If you opened this link inside email or chat, use **Open in browser** and continue in Chrome, Firefox, Edge, or Samsung Internet. Embedded viewers can block APK downloads.

## Install

1. Download only from `github.com/terry77075/MyHealthData-Android-Releases`.
2. In your browser's Downloads list or Android Files app, open **Downloads** and tap `MyHealthData.apk`.
3. If Android blocks the source, allow installs only for the browser or Files app you are using. Return to the APK and retry. You may turn that source permission off afterward.
4. Continue past the APK warning only when the GitHub source and filename are correct.
5. Tap **Install**, then **Open**. Follow the first-open prompts and grant only permissions needed for features you choose.

Keep Play Protect and other Android protections enabled. If Android reports an unexpected signature, package, or security problem, cancel and contact support.

## Updates, backup, and local data

Download from the same link and install over the existing app. **Do not uninstall first**, because uninstalling can remove local health records.

Before updating or changing phones, use MyHealthData's **Backup & Transfer** feature. Keep the backup and its recovery information safe and separate. Do not send them to support.
