# Install RideLoop Beta on Android

> **Beta · Android only.** The current public stable beta is RideLoop v4.

## Download

[Download the latest RideLoop Beta (RideLoop-Beta.apk)](https://github.com/terry77075/RideLoop-Support/releases/download/beta-latest/RideLoop-Beta.apk)

If you opened this link inside email or chat, use **Open in browser** and continue in Chrome, Firefox, Edge, or Samsung Internet. Embedded viewers can block APK downloads.

## Install

1. Download only from `github.com/terry77075/RideLoop-Support`.
2. In your browser's Downloads list or Android Files app, open **Downloads** and tap `RideLoop-Beta.apk`.
3. If Android blocks the source, allow installs only for the browser or Files app you are using. Return to the APK and retry. You may turn that source permission off afterward.
4. Continue past the APK warning only when the GitHub source and filename are correct.
5. Tap **Install**, then **Open**. Grant only the permissions needed for features you choose.

Keep Play Protect and other Android protections enabled. If Android reports an unexpected signature, package, or security problem, cancel and contact support.

## Updates and local data

Download from the same link and install over the existing beta. **Do not uninstall first**, because uninstalling can remove local activity data. Before an update, keep copies of exported routes or activity information you cannot replace.
