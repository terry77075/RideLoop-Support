RideLoop Support

Help for the public RideLoop Android beta.

Install or update

Use the Android installation guide for the fixed download link, source-specific install permission, first open, and safe in-place updates. RideLoop is currently a beta.

Location permission

RideLoop needs Android location permission to record routes and calculate GPS-based activity information. Grant only the level needed for the recording features you use, and make sure device Location is on.

Background tracking

GPS recording can be affected by Android battery optimization, location permissions, and whether the phone allows RideLoop to run while the screen is locked. If a recording stops unexpectedly, check the app's Location and Battery settings before the next activity.

Activity history and saved routes

Activity history and saved routes are separate. Removing activity history should not remove routes that you deliberately saved for future use. Before an update, keep copies of any exported activity or route information you cannot replace.

Need help?

Email rideloopsupport@gmail.com. Include your phone model, Android version, RideLoop version, what you expected, and the exact error text. Hide personal information in screenshots.
