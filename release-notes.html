Android v32

outabit Beta v32 for Android

Version: 1.1
Version code: 2026101232
Package: com.localloops.app.beta
Published: October 27, 2026
Status: Public prerelease beta, not a production release.

What changed
- Added a dedicated Lap Dashboard with a neutral previous-lap Time or Distance reference, a spinning lap-history wheel, and a setting that can automatically focus the Lap Dashboard after recording a lap. The automatic-focus default applies when no preference has been saved; an explicit saved choice is preserved.
- Added six coordinated appearance palettes with live Screen 1 and Lap Dashboard previews, Apply/Cancel, and an empty-dashboard long-press shortcut.
- Refined Screens 1 through 4 with larger centered speed readings, regular-weight lowercase units, aligned Trip and Odometer rows, and responsive long-value fitting in portrait and landscape.
- Added a safe Cancel action to the finish card, more forgiving Stop and dashboard navigation touch handling, and dismissible continuation and startup sensor notices.
- Corrected History and Trip report drafts to address support@outabit.com.
- Bounded bicycle-sensor connection attempts so a sleeping sensor cannot hold the retry loop indefinitely. The generic startup warning waits two minutes while the amber status remains visible; actionable Bluetooth permission or powered-off errors remain immediate.

Validation
- TypeScript and all 340 automated tests passed against source commit 41a9e86.
- The exact signed APK was installed in place on the test Moto G as v32. The original install identity remained intact, existing totals were visible, Home rendered normally, and no recovery card or fatal launch error appeared.
- APK alignment, SHA-256 and v2/v3 signatures were verified with the permanent Beta signing identity.
- Source content was committed after the already-tested APK was built. The artifact's embedded developer provenance identifies base commit a40d1f5 with a dirty working tree; the exact source content is preserved in commit 41a9e86.
- No paid cloud build was used.

Testing limits and known issues
- The sleeping-sensor retry and two-minute warning behavior passed automated tests but has not yet been validated with a sleeping physical sensor on this build.
- Live Screens 1 through 4 were not opened during the final installation check because that would require starting an outing. Their portrait, landscape, long-value and navigation behavior is covered by automated tests.
- The green return arrow can overlap the bottom map legend on the Map & Digital Dashboard.

Install or update
1. Download RideLoop-Beta.apk from the permanent link on the install page.
2. Open it and follow Android's installer prompts. Permit installs from the browser or file manager if Android asks.
3. Install over the existing Beta to preserve local outings and settings. Do not uninstall first.
4. Keep Android protections enabled. Cancel if Android reports an unexpected signing or package mismatch.
5. This uses the separate package com.localloops.app.beta.

Android v26

outabit Beta v26 for Android

Version: 1.1
Version code: 2026101226
Package: com.localloops.app.beta
Published: October 21, 2026
Status: Public prerelease beta, not a production release.

Getting the installer
Use the official installer link provided by the outabit team.

What changed
- Improved BLE discovery: include unnamed detected devices, merge duplicate advertisements, show signal strength, and sort strongest first with stable selection order.
- Use advertised Cycling Speed and Cadence (CSC) service identifiers as compatibility clues. Show Previously connected, Likely compatible sensor, or Unknown compatibility; confirm supported services and characteristics only after Connect is selected.
- Preserve saved sensor connections and speed/cadence measurement behavior. Normal Cancel no longer reports a misleading lost-sensor warning.
- Add customizable activities: add, rename, reorder, hide and restore, with independent goals and default screens. Preserve history and include hidden activities with recorded outings in Stats.
- Add the Home activity long-press shortcut and direct return to Home. Omit empty Stats activity rows and explain empty periods.
- Includes outabit branding and the existing video format/duration, camera, artwork, dashboard and odometer improvements.

Validation
- TypeScript and all 327 automated tests passed.
- Actual speed sensor tested on physical iPhone and Android: discovery, live speed, saved recognition and reconnect. Final cancellation and editor-label refinements also covered by regression tests.
- This is the exact signed APK installed on the test Moto G as v26; launch checked after in-place update.
- Android release built locally; no additional cloud build or publishing charge.
- APK alignment and signature verified with the permanent Beta signing identity.
- Supports ARM64 and 32-bit ARM devices running Android 7.0 or newer. This APK does not include x86 emulator binaries.

4. Keep Android protections enabled. Cancel if Android reports an unexpected signing or package mismatch.
5. This uses the separate package com.localloops.app.beta.

RideLoop Beta 1.1 for Android
Immutable build: 2026101204 (v4)
Package: com.localloops.app.beta
Status: Public prerelease beta; this is not a production release.
Published: October 12, 2026

What changed
- Reorganized Settings into compact status rows with focused detail pages and clear Back navigation.
- Preserved GPS, weather briefing, bike setup, tide station, landscape riding view, default riding screen, navigation audio, elevation/calibration, and general settings.
- Added an explicit Save to Gallery action for outing images.
- Corrected Android native dependency packaging so ExpoAsset, Expo constants/fonts, and Expo MediaLibrary are embedded in the installer.
- Retained the Android Expo shared-object lifetime fix used by asynchronous native calls.

Validation performed
- Installed in place over the prior RideLoop Beta while preserving imported outings and saved routes.
- Passed two independent cold-launch checks without a crash, process death, or force-finish event.
- Confirmed History entries and route-saved status remained visible.
- Saved a valid, nonblank outing image to Gallery without granting media read/write permissions.
- Verified Android package, version, four ABI architectures, APK alignment, and v2/v3 signatures.
- Project typecheck and all 232 automated tests passed.

Install or update
1. Download RideLoop-Beta-1.1-20261012-v4.apk.
2. Open the downloaded APK and follow Android's installer prompts. Android may ask you to permit installs from the browser or file manager you used.
3. To preserve existing RideLoop Beta data, install this APK over the existing Beta. Do not uninstall the existing Beta first.
4. This installer uses the separate package com.localloops.app.beta and does not replace a production RideLoop package.
